# ASN.1 Decoder — расшифровка сертификатов и запросов

Понятный просмотр X.509-сертификатов и запросов на сертификат (CSR, PKCS#10) с русскими названиями полей. Задуман как дружелюбная замена [lapo.it/asn1js](https://lapo.it/asn1js/) для тех, кому нужно не дерево ASN.1 и HEX, а ответ на вопрос «что зашито в сертификате».

**Открыть:** https://aiekseu.github.io/asn1-decoder/

Всё считается в браузере: данные никуда не отправляются, страница работает без интернета (можно скачать репозиторий и открыть `index.html` с диска).

## Возможности

- **Форматы:** PEM (в том числе `NEW CERTIFICATE REQUEST` и PEM, склеенный в одну строку), Base64 без заголовков, HEX, бинарный DER. Файлы `.cer`, `.crt`, `.der`, `.pem`, `.csr`, `.req`, `.p10`, контейнеры PKCS#7 (`.p7b`, `.p7c`) с цепочкой сертификатов.
- **Ввод:** вставка в поле, `Ctrl+V` в любом месте страницы, перетаскивание файла, выбор файла.
- **Сводка:** владелец, тип (ЮЛ / ИП / ФЛ), статус и остаток срока действия, срок закрытого ключа, ИНН, ОГРН, СНИЛС, средство ЭП, назначения, отпечаток SHA-1.
- **Российская специфика:** ГОСТ Р 34.10/34.11-2012 и параметры ключей, ИНН/ОГРН/ОГРНИП/СНИЛС с проверкой контрольных сумм, средства ЭП владельца и издателя, класс средства ЭП (КС1–КА1), способ идентификации, атрибуты запросов КриптоПро и Microsoft (компьютер, пользователь, криптопровайдер, версия ОС, шаблон).
- **Назначения ключа (EKU):** названия ЭТП, госсистем, Росреестра, ФРДО и т. д. Для неизвестных OID — владелец ветки по государственному реестру OID РФ.
- **Поиск** по названиям, значениям и OID с подсветкой (`/` — перейти к поиску).
- **Копирование:** любое значение отдельно или весь разбор текстом.
- **Мелочи:** светлая и тёмная тема, скрытие OID, исправление «кракозябр» (строк, закодированных в UTF-8 дважды), сверка идентификатора ключа с расширением SKI (в том числе по алгоритму КриптоПро).

Подпись не проверяется — страница показывает только содержимое.

## Структура

```
index.html               разметка страницы
assets/styles.css        стили, светлая и тёмная тема
src/
  registry.js            реестр OID РФ: ветка → организация (генерируется)
  oids.js                справочник OID с русскими названиями
  asn1.js                разбор DER/BER и примитивов
  hash.js                SHA-1, SHA-256
  decoder.js             модель документа: секции, поля, проверки
  render.js              отрисовка модели в DOM
  samples.js             встроенные примеры (вымышленные реквизиты)
  app.js                 состояние, поиск, копирование, события; версия APP_VERSION
scripts/update-registry.py   обновление src/registry.js с oid.iitrust.ru
tests/decoder.test.mjs   тесты разбора (Node.js, без зависимостей)
.github/workflows/pages.yml  тесты и публикация на GitHub Pages
```

Скрипты обычные (не ES-модули), чтобы страница открывалась и с диска по `file://`. Порядок подключения в `index.html` важен: справочники → разбор → модель → отрисовка → приложение.

## Разработка

Сборка не нужна. Для локального просмотра:

```bash
python3 -m http.server 8765
```

Тесты (Node.js 18+):

```bash
npm test
```

Обновить реестр OID РФ:

```bash
python3 scripts/update-registry.py
```

### Как добавить название OID

Допишите строку в `OIDS` в [`src/oids.js`](src/oids.js): `'1.2.643.x.y': ['краткое имя', 'Русское название']`. Рядом с группой укажите источник. Если источник даёт только общее описание, по которому непонятно, к чему относится OID, лучше оставить его без названия — сработает подсказка по реестру.

Источники названий:
- [ОИДы в сертификатах — УЦ «АЙТИКОМ»](https://cs-crimea.ru/spravka/stati-i-spravka/108-oidy-v-sertifikatakh)
- [Реестр OID РФ](https://oid.iitrust.ru/oid_search/) — владельцы веток
- тарифы keydisk — для OID, которых нет в справке выше
